# 闪暖日活校准 App

这是全流程校准 App 的 0.5.0 测试版。它会把工作区中的 `闪暖日活流程.md` 和 `闪暖日活流程图片` 打包进 APK，通过无障碍悬浮窗逐步显示和现场校准现有流程。

当前版本不会自动点击游戏。每一步由用户手动完成，确认无误后点击悬浮窗的“下一步”；发现步骤文字、顺序或点击区域有误时点击“标记有误”。App 会记录当前任务和步骤，并在隐藏悬浮窗后保存一张原分辨率现场截图。

## 引导中校准流程

- 首页不再提供脱离引导的“编辑流程结构”入口。所有增删判断都在游戏引导现场完成。
- 悬浮窗点击“步骤校准”，可选择“插入大流程”“插入小步骤”或“删除当前步骤”；编号自动顺延，操作同时进入“流程校准记录”。
- 插入或补充点击位置时，App 会先隐藏悬浮窗并截取原分辨率游戏画面，再进入截图选点页。
- 在截图上点击实际目标后，App 会保存红圈、原图像素坐标、截图尺寸和横纵相对坐标，并绑定到对应流程步骤。
- 任何已有步骤都可使用“点选位置”补齐坐标，不只限于新插入步骤。
- 新插入内容先使用占位说明，完成一轮后在“流程校准记录”中统一编辑备注并导出 Markdown/JSON。

## 分支流程校准

1. 在分支出现前的当前步骤点击“在当前步骤后创建分支”。原有后续步骤自动作为分支1。
2. App 截取当前画面；拖动矩形框选分支2特有且稳定的按钮、标题或图标，保存后进入分支2。
3. 在分支2中使用“插入小步骤”“点选位置”“上一步/下一步”记录完整路径。
4. 到达分支2的稳定结束状态后点击“分支2结束”。App 保存结束截图并把引导切回分支1起点。
5. 将游戏重新操作到判断位置，按原流程完成分支1；到达相同逻辑状态时点击“分支1结束并汇合”。
6. 两条分支连接到同一个逻辑汇合状态，随后继续原主流程。动态人物、动画和数值可以不同，不比较两张完整截图。

分支判断区域、分支2步骤、两个结束状态以及稳定步骤 ID 会写入独立的分支 JSON/Markdown，并随校准记录一起导出。

## 在 Android Studio 中打开

1. 打开 `ShiningProbe` 文件夹。
2. 等待 Gradle 同步完成。
3. 选择 `app` 运行配置。
4. 连接手机后点击 Run，或执行 `gradlew.bat assembleDebug` 构建 APK。

构建时 `syncGuideAssets` 会自动同步项目上一级目录中的流程 Markdown 和参考图。因此修改流程后重新构建，即可在 App 中看到新步骤。

## 手机使用流程

1. 安装 APK，打开“闪暖日活校准”。
2. 点击“打开无障碍设置”，启用“闪暖日活校准”服务。
3. 返回 App，点击“选择任务并开始引导”。
4. 勾选本次需要校准的任务，点击“开始引导并打开闪耀暖暖”。
5. 在游戏中拖动悬浮窗到不遮挡操作的位置。
6. 人工完成当前步骤后点击“下一步”；需要查看录屏参考截图时点击“参考图”；需要增删内容或采集坐标时点击“步骤校准”。
7. 发现错误时点击“标记有误”。标记不会自动切换到下一步。
8. 整个流程完成后回到 App，进入“查看、编辑和导出校准记录”；点击截图预览或“查看清晰原图”可以按原始分辨率查看并上下滚动。
9. 点击“导出 Markdown 和 JSON 汇总”，再将导出目录复制到电脑统一修改流程。

## 导出位置

- 校准记录：`Android/data/com.example.shiningprobe/files/Documents/guide-review`
- 增删记录、点击坐标、原图和红圈标注图：同一 `guide-review` 目录
- 原能力测试文件：`Android/data/com.example.shiningprobe/files/Documents/probe`

每条校准记录包含会话编号、任务、步骤、原步骤文字、修改说明和现场截图路径。

校准记录页面每页显示 6 条记录，缩略图在后台按需加载；换页和离开页面时会释放旧缩略图。无论记录数量多少，都不会再一次性解码全部清晰截图。

## 第一版安全边界

- 不主动点击游戏，不自动消耗体力、红心、金币或抽卡次数。
- “标记有误”只保存记录和截图。
- 结束引导不会删除已有标记。
- 原来的控件树、截图、点击、滑动和返回能力测试仍保留在首页底部。
